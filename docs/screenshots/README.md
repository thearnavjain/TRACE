# TRACE screenshots

These four PNG files are genuine captures of the locally running TRACE dashboard. The root README embeds them from this directory:

- `dashboard.png` — dashboard introduction and historical session/driver controls.
- `driver-comparison.png` — selected candidate lap times, sectors, sample summaries, and the lap-time explanation.
- `telemetry-trace.png` — interactive speed chart, elapsed-time control, and nearest returned samples.
- `comparison-insights.png` — plain-English lap-time and elapsed-time speed-gap insights.

The screenshots show candidate-lap results; official lap validity and personal-best status remain unverified. The telemetry comparison is elapsed-time based and is not aligned by circuit position.
